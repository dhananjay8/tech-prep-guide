# Tech Prep Guide

Purpose-based interview preparation for coding, architecture, practical exercises, and technology deep dives.

## Study Tracks

- [Algorithms and DSA](./algorithms/README.md) — pattern guides, Top Interview 150, and difficulty-grouped solutions.
- [System design](./system-design/README.md) — scenario walkthroughs, topics, and an interview template.
- [Software design](./software-design/README.md) — object-oriented design patterns and trade-offs.
- [Machine coding](./practice/README.md) — UI and full-stack prompts grouped by use case.
- [SQL](./databases/README.md) — SQL interview exercises and local solutions.
- [Technology notes](./technologies/README.md) — cloud, DevOps, Kubernetes, languages, AI, and testing.
- [Company prep](./interview-prep/README.md) — role-specific case studies and interview drills.

## Suggested Study Path

1. Pick a [DSA pattern](./algorithms/guides/README.md), then attempt a problem from the [Top Interview 150](./algorithms/study-plans/top-interview-150.md) before opening its solution.
2. Practice a [machine-coding question](./practice/machine-coding/Questions.md) and a [system-design scenario](./system-design/README.md).
3. Review [design patterns](./software-design/design-patterns/README.md), [SQL](./databases/sql/README.md), and the relevant [technology track](./technologies/README.md).
4. Use [company prep](./interview-prep/companies/README.md) for role-specific rehearsal.
